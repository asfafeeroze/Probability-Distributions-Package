# Probability Distributions Package

A Python package for working with and visualizing probability distributions.

This project implements probability distribution classes using object-oriented programming in Python. It currently supports **Gaussian (Normal)** and **Binomial** distributions and provides methods for calculating distributions and provides methods for calculating distribution statistics, probabilities, visualizing distributions, and combining compatible distributions.

## Features

### Gaussian Distribution
The Gaussian class supports:

* Calculating the mean of a dataset
* Calculating sample or population standard deviation
* Calculating the probability density function (PDF)
* Plotting a histogram of data
* Plotting a normalized histogram alongside the Gaussian PDF
* Adding two Gaussian distributions
* Displaying the mean and standard deviation of a distribution

  ### Binomial Distribution
  The Binomial class supports:

  * Calculating the mean
  * Calculating the standard deviation
  * Estimating p and n from data
  * Calculating probabilities using the Binomial PMF
  * Plotting binary outcome data
  * Plotting the Binomial probability distribution
  * Adding two Binomial distribution
  * Adding two Binomial distributions with the same probability of success
